# Maven Fuzzy Factory – Toy Store Data Analysis

## Project Overview

In this project, I analyzed e-commerce data from Maven Fuzzy Factory to understand sales performance, website traffic, product revenue, conversion rates and refunds.

The main objective was to identify business trends, understand product performance and generate actionable insights using data analytics tools.

## Tools & Technologies

Python: Pandas, NumPy

SQL: PostgreSQL

Power BI: Dashboard & Visualization

DAX: KPI calculations

## Datasets

The project includes:

Orders

Order Items

Products

Website Sessions

Website Pageviews

Order Item Refunds

## Key Insights

Total Revenue: $1.94M

Total Orders: 32.3K

Average Order Value: $59.99

Google Search generated the highest website traffic.

bsearch achieved a higher conversion rate than gsearch.

The Original Mr. Fuzzy was the top revenue-generating product.

Socialbook had the lowest conversion rate among the analyzed sources.

 ## Business Recommendations

Optimize marketing campaigns based on conversion rates rather than traffic alone.

Investigate low conversion rates from Socialbook.

Focus on best-selling products and inventory planning.

Analyze refunds to identify product quality issues.

Improve website traffic tracking and marketing attribution.
